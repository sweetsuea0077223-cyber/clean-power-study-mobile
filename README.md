# 潔淨動力英文備考

- [原手機版](https://sweetsuea0077223-cyber.github.io/clean-power-study-mobile/)：保留首次發佈版本。
- [手機版・含出處版](https://sweetsuea0077223-cyber.github.io/clean-power-study-mobile/source-pages.html)：獨立頁面，180題均可開啟出處原頁，共95張內嵌投影片，支援跨頁與2倍/3倍放大。

兩個版本均含180題英文四選一、100張單字卡及30題模擬考，涵蓋材料、測試及失效模式三份教材。

## 學習紀錄

兩頁在同一網站來源，共用同一個localStorage學習紀錄，原有作答、收藏、單字熟悉度及未完成模擬考可接續。更新不清除紀錄。
進度不會上傳到GitHub或雲端；不同裝置/瀏覽器不會自動同步。可在「複習」匯出或匯入JSON備份。

## GitHub Pages

發布來源為main分支根目錄。原手機版index.html固定保留；含出處版由source-pages.html獨立提供。
每頁皆為可攜式單檔HTML，不依賴外部字型或網路API；原教材PDF/PPTX及私人NotebookLM生成歷程不在儲存庫中。
網站需要網路載入，未實作斷網快取。題庫是教材模擬練習，無法保證命中正式考題。
