# 潔淨動力英文備考｜手機版

以手機直向操作為主的鋰離子電池課程英文備考工具。

- 180題英文四選一，涵蓋材料、測試與原子層級失效模式三份教材。
- 每回30題模擬考，三份教材各10題；交卷後顯示中文解析與教材頁碼。
- 每題可開啟對應出處原頁，95張教材頁面內嵌，支援2倍/3倍放大及跨頁切換。
- 100張單字卡、生字點讀、錯題、收藏與個人複習標記。
- 所有內容內嵌於index.html；不依賴外部字型或網路API。

## 學習紀錄

作答、字卡熟悉度與未完成模擬考保存在目前瀏覽器的localStorage中，不會上傳到GitHub或伺服器。
同一裝置、同一瀏覽器及同一網站來源可接續。換裝置、換瀏覽器或清除網站資料，不會自動同步。
可在「複習」匯出/匯入JSON備份。從本機預覽搬到正式網址前，請先匯出備份再到正式網址匯入。

## GitHub Pages

發布來源使用main分支的根目錄。此儲存庫僅收錄備考頁面，不包含完整教材PDF、原PPTX或NotebookLM私人生成歷程。
網站為公開的靜態網頁。從GitHub Pages開啟需要網路；如需在其他情況下使用單檔HTML，請以支援JavaScript的檢視器開啟。

題庫是依課程資料製作的模擬練習，不保證命中正式考題。
